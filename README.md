# ساندويتش بانل وديكورات ابو تالين

موقع عربي متجاوب لتركيب الساندويتش بانل وديكورات الجبس بورد والجدران والأسقف داخل مدينة الرياض.

- الموقع: https://abu-talin-electric-plumbing.vercel.app/
- التواصل: 0505174342
- التقنية: HTML + CSS + JavaScript
- الاستضافة: Vercel

## التشغيل والفحص

```bash
npm run check
npm run build
```

ينتج أمر البناء نسخة النشر الثابتة داخل `public/`.

## المحتوى والبيانات المنظمة

المصدر الموحد للخدمات والهوية هو `scripts/services-data.mjs`، ويولّد
`scripts/generate-services.mjs` الرئيسية والخدمات ومن نحن والتواصل وصفحات الخدمات
الثلاث. يحافظ البناء على توقيع المطوّر وينتج تعريف WebSite واحدًا داخل شبكة JSON-LD
موحدة تضم النشاط والخدمات والصفحة ومسارات التنقل المناسبة.

روابط الكهرباء والسباكة السابقة تعرض روابط الخدمات الحالية مع `noindex, follow`؛
لا تظهر في خريطة الموقع أو التنقل أو كتالوج النشاط. خريطة الموقع تضم الصفحات
السبع النشطة فقط. لم تُغيّر بيانات Google Business Profile ضمن هذا التحديث.

نموذج الطلب يجهّز رابط رسالة واتساب على جهاز الزائر، ويتيح مراجعتها وإرسالها
داخل واتساب. لا يرسل النموذج تلقائيًا ولا يخزّن تفاصيل الطلب في خادم الموقع.

يشمل الفحص مطابقة الهاتف والروابط والهوية، وصحة JSON-LD ومراجع الخدمات،
والروابط الداخلية والصور وسياسة الفهرسة وملاءمة خريطة الموقع للصفحات النشطة.
لا يثبت نجاح الفحص حصول الموقع على ترتيب أو نتيجة غنية في Google.
